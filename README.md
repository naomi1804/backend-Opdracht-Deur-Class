# backend-Opdracht-Deur-Class
de backend opdracht Deur Class

hier onder komt hoe je het runt en de opdracht

hoe run je het:

1. download de code en zet hem ergens in je folders.
2. ga na waar je code staat
3. klik op de balk waar de locatie van je code staat.
4. verander wat er staat ma "cmd" (dit opent je comands)
5. run de code "php -S localhost:8000 (naam code bv. index.php)"
6. je ziet nu een link na een pagina
7. copy de link en paste hem in welke search engine je gebruikt
8. nu is je website zichtwaar

de opdracht:

Maak de deur af (en/of schrijf deze klasse om in een andere programmeertaal):

De deur is het object en de index/Program is de persoon die het gebruikt (die dus echo gebruikt). De klasse mag dus niets laten zien op het beeldscherm.
De deur heeft een slot en kan worden ontgrendeld door de sleutel naar links of rechts te draaien.
Met de klink kan de deur worden opengemaakt. Dat kan alleen als die niet op slot is!
Loop door de deur en laat dat zien op het scherm.
Laat ook de foutmeldingen zien!
